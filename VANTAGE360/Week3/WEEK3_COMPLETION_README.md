# VANTAGE360 Week 3 Data Analyst Deliverables

Completed DA-01 through DA-13 using the Week 2 analytical foundation and the supplied ML risk score CSV.

## DA-08 limitation
The supplied ML file contains customer_id, attrition_risk_proxy, risk_score, and risk_category. It does not contain model evaluation metrics, time-based train/test dates, feature importance, model version, or threshold methodology. Therefore this package reconciles the delivered ML outputs with the analytical proxy but does not independently verify the model's time-based test performance.

## Power BI
PBIX cannot be generated here. DA-06 and DA-09 specifications and dashboard-ready datasets are included for Power BI implementation.

## Campaign limitation
The Week 2 campaign source did not provide customer_id/transaction_id keys, so direct campaign-to-customer-to-revenue attribution remains unsupported.
