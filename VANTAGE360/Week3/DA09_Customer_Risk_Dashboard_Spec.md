# DA-09 Customer Risk Dashboard

KPI cards: ML High Risk, ML Medium Risk, ML Low Risk, Proxy High Risk, Proxy/ML Exact Agreement.

Charts: ML risk distribution; risk by region; risk by lifecycle segment; proxy vs ML matrix.

Table: customer_id, ML risk score/category, proxy risk, LTV, orders, days since last purchase, segment, region.

Use the ML score as a model output, not as a proven churn probability unless the ML documentation explicitly defines it that way.
